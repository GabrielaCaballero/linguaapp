# 03 · UX & visual design — Lingua v2

_UX/visual designer, 2026-11-12. Read with 00-brief. Everything here is meant to be buildable in plain CSS + React with no animation or UI library._

---

## 1. Critique of v1 (from `docs/screenshots/`)

The v1 look is warm and calm, which is worth keeping. The problem is that it reads like a **research notebook rather than a game**. Every screen explains its own theory instead of letting you play.

| Screen | What goes wrong |
|---|---|
| **01 Today** | There are **five competing cards** before you reach the button: sleep note, Today, milestone, the "four strands" bar and the Ties log. The primary action sits mid-screen, out of easy thumb reach. Chips like "14 to review · 8 new · guess first · speed round" are jargon. "Nation's 4 strands" means nothing to a learner. There is no sense of where you are in a course. |
| **02 Guess first** | The concept is good, but the "GUESS FIRST · NO WRONG ANSWERS YET" eyebrow is shouty. The dashed-orange "your pick" state and the green "correct" state look like two selections, so it's unclear which one is right. The teaching card sits *below* the options, so on smaller phones you have to scroll to read it. |
| **03 Almost / 04 Miss** | The feedback text is good. But feedback appears **inline at the top** while the Continue button is at the bottom, leaving 50% dead space in between. There is no motion, sound or haptic, so a right answer and a wrong one *feel* the same. The fluency-illusion lecture comes at the moment you're already annoyed. "My answer was right — count it" is a tiny underlined link. |
| **05 Build sentence** | The tiles were already placed and there is no visible word bank or answer line, so it's unclear what was interactive. The tiles are small (≈40px tall). |
| **06 Speed round** | Two options floating at the top of a mostly empty screen. The timer "43s" is small and in the corner with no ring or urgency, and there are two progress indicators (the bar and 1:00). It doesn't feel like a mode change. |
| **07 Session done** | "1 minutes · 24 tasks · 25% recalled" is a low-energy stat dump, and 25% recalled feels like a failure. The emoji is the only delight. Nothing new unlocks, there's no streak/goal moment, and no "what's next". |
| **08 Progress** | A wall of text explaining the fluency illusion, plus a strands chart with no actionable meaning. "1 known of 75" is demotivating. There's no visual of growth over time. |
| **09 Milestones** | Personal content (to be removed). Dates and warnings create anxiety, not motivation. |
| **10 German Today** | The placement question is crammed into a Today card above the Start button. That makes two decisions at once. |
| **11 Add from class** | A plain form. Useful, but it's a power feature promoted to a top-level destination. |
| **12 More** | Native `<select>`s for core settings, the plan start date (obsolete) and the theory "About" text are all mixed together. |

**Systemic issues:** the language switch is a segmented control repeated on every page (it should be global and rarely touched). Hierarchy is flat (everything is a white rounded card of the same weight). Feedback is not multisensory. There's no persistent sense of progress (no path, no ring, no streak). Copy explains the learning science instead of *embodying* it.

---

## 2. Design principles for v2

1. **One obvious next action.** Every screen has exactly one primary button, in the bottom thumb zone. Home is basically one big button.
2. **Show, don't lecture.** The learning science lives in the mechanics (guess first, spacing, confidence). Explanations go behind an ⓘ tap or into a one-line tip, never in paragraphs.
3. **Progressive disclosure.** New users see Home + Path. Stats, "Add from class", the AI tutor and fine settings reveal themselves later (after the first session or behind Profile).
4. **Every answer gets a felt response.** Colour + motion + haptic (+ optional sound) within 100 ms. Right answers feel springy; wrong ones feel gentle, never punishing.
5. **Calm but alive.** A warm, paper-like base with saturated per-language accents. Motion is short and physical (springs, not fades). Nothing blinks or nags.
6. **Celebrate effort and consistency, not perfection.** Rings fill for minutes practised, and streaks have a built-in "rest day". Accuracy is shown as "got stronger", not "% wrong".
7. **Thumb-first.** Primary controls go in the bottom 40% of the screen. Nothing important sits in the top corners except Close.

## 3. Visual system

All tokens live as CSS custom properties in `globals.css`. Per-language accents switch via `[data-lang="it"|"de"]` on `<html>`. Dark mode uses `@media (prefers-color-scheme: dark)` **plus** a manual override `[data-theme="dark"|"light"]` (setting: System / Light / Dark).

**Per-language accent** (`--accent`, `--accent-press`, `--accent-soft`, `--on-accent`):

| | Light accent / press / soft | Dark accent / press / soft | Personality |
|---|---|---|---|
| **Italian** "Terracotta" | `#C4452A` / `#A33620` / `#FBE6DF` | `#FF8B6B` / `#FF6F4A` / `#3A211A` | warm, sunny |
| **German** "Rhine Blue" | `#2E5BD8` / `#2349B3` / `#E3EAFC` | `#8EA8FF` / `#7090FF` / `#1B2340` | crisp, cool |

`--on-accent` is `#FFFFFF` in light mode and `#121110` in dark mode. Both light accents give ≥4.6:1 with white text. In dark mode, text on the light accent is dark. Future languages just add one more `[data-lang]` block (e.g. Spanish "Saffron", French "Lavender").

### 3.2 Typography (Google Fonts via `next/font/google`, self-hosted at build time, so it works offline)

- **Display / target-language words: _Fraunces_** (variable, `opsz` axis on, weights 500 and 650, `SOFT` 50). Use it for the word being learned, screen titles and big numbers. It keeps v1's literary warmth but is rounder and friendlier.
- **UI: _Inter_** (variable, weights 400 / 500 / 600 / 700, `font-feature-settings: "ss01","cv11"`, tabular numbers for timers and stats).

| Token | Size / line-height | Family / weight | Use |
|---|---|---|---|
| `--t-hero` | 40 / 44 | Fraunces 650 | prompt word, results headline |
| `--t-title` | 28 / 34 | Fraunces 600 | screen titles |
| `--t-h2` | 20 / 26 | Inter 650 | section, card titles |
| `--t-body` | 17 / 24 | Inter 400 | body, options (17 = iOS default, prevents zoom on inputs) |
| `--t-label` | 15 / 20 | Inter 500 | buttons secondary, chips |
| `--t-caption` | 13 / 18 | Inter 500, +0.02em | meta, eyebrows (sentence case, **no all-caps**) |
| `--t-stat` | 34 / 36 | Inter 700 tabular | numbers on results/profile |

Sizes use `rem` so Dynamic Type / browser zoom scale them. Cap text at 200% zoom without layout breakage.

### 3.3 Spacing, radii, elevation

- **Spacing (4-pt base):** `--s1 4px · --s2 8px · --s3 12px · --s4 16px · --s5 20px · --s6 24px · --s8 32px · --s10 40px · --s12 48px`. Screen gutter is 20px. Gap between cards is 12px. Gap between sections is 32px.
- **Radii:** `--r-sm 10px` (chips, tiles) · `--r-md 16px` (option buttons, inputs) · `--r-lg 24px` (cards, bottom sheets) · `--r-pill 999px` (primary buttons, tab indicator).
- **Elevation:** mostly flat. Only three levels:
  - `--e1: 0 1px 0 var(--line)` for resting cards. A border-bottom "lip" gives tactile depth like a key.
  - `--e2: 0 6px 20px rgb(28 26 23 / .08)` for floating sheets and the tab bar.
  - `--e3: 0 12px 40px rgb(28 26 23 / .16)` for modals and celebration.
  - In dark mode, shadows become `none`, and elevation is expressed by a lighter surface (`--surface` → `#24211E`).
- **Pressable "3D" buttons** (signature): the primary button has `box-shadow: 0 4px 0 var(--accent-press)`. On `:active` it does `transform: translateY(3px)` and the shadow drops to 1px. Option tiles use the same trick with `--line`. This is what makes Duolingo-style UIs feel tappable, and it's pure CSS.

### 3.4 Iconography

- **Inline SVG React components** in `src/components/icons.tsx`: 24×24 viewBox, `stroke="currentColor"`, `stroke-width 2`, round caps and joins. No icon fonts, no external sprite.
- Set: home, path, user, settings, close, back, speaker, speaker-slow (turtle), mic, check, x, flame, ring, lock, star, sparkle (AI), keyboard, cards, wifi-off, info, plus.
- Icons are always paired with a label in navigation. Icon-only buttons need `aria-label`.

### 3.5 Illustration & emoji policy

- **No mascot** (cost and tone). Instead, there's a **language "seal"**: a 56px circle in the accent colour with a 2-letter monogram "IT"/"DE" set in Fraunces. Use it in the switcher, onboarding and the share card. **No flags** in UI chrome. Flags are about nations, not languages (Swiss/Austrian German speakers, Swiss Italian). A small flag may appear only in the language picker list.
- Emoji are allowed **only in content and celebrations** (🎉 on results, 🔥 rendered as our SVG flame instead). They are never used as icons for UI controls (v1 used ✏️ 📜 for menu items; drop that).
- Unit illustrations: simple geometric SVG "postcards" per unit (e.g. coffee cup, train, house), with 2 colours (accent + text-2). These are generated as inline SVG, so no image assets are needed.

## 4. Motion & feedback

**Easing tokens:** `--ease-out: cubic-bezier(.2,.8,.2,1)`; `--spring: cubic-bezier(.34,1.56,.64,1)` (overshoot). **Durations:** `--d-fast 120ms` (press), `--d-med 220ms` (sheets, state), `--d-slow 420ms` (celebration). Everything is CSS `@keyframes`/transitions toggled by class or `data-state`. JS is only used for confetti particles (≤40 absolutely-positioned spans, removed after 1.2 s).

| Moment | Visual | Haptic (`haptic()` helper) | Sound (opt-in) |
|---|---|---|---|
| Tap option | press-down 3px | `light` 10ms | soft tick |
| **Correct** | Chosen tile turns `--ok` and does `pop` (scale 1→1.06→1, spring). The feedback **sheet slides up from the bottom** (220ms) with a ✓ icon that draws via `stroke-dashoffset`. The progress bar advances with a little shine sweep. | `success` [12, 40, 12] | rising two-note chime |
| **Almost (typo)** | Amber sheet. The diff is highlighted: the missing letter appears underlined in the corrected word. | `light` | single neutral note |
| **Incorrect** | Tile does `nudge` (translateX 0,-6,6,-4,0 over 300ms; **not** a violent shake). Red X icon, correct answer shown big in Fraunces, auto-plays audio once. | `[30]` single | low soft tone (never a buzzer) |
| 3-in-a-row combo | Progress bar glows gold and a "3 in a row!" chip floats up 24px and fades out | `success` | brighter chime |
| Session complete | Full-screen results with ring fill animation + confetti burst from the button origin | `[15,60,15,60,30]` | short arpeggio |
| Streak +1 | Flame scales in with a spring, number rolls (CSS `translateY` digit column) | `success` | — |

- **Haptics helper:** `haptic(kind)` calls `navigator.vibrate(pattern)` only if it exists *and* the user setting "Vibration" is on (default **on**). Ignore the return value. iOS Safari doesn't implement the Vibration API, so feedback must never depend on it. Engineering may optionally use the hidden `<input type="checkbox" switch>` trick for iOS 17.4+ taps, and Capacitor's Haptics plugin later.
- **Sounds:** Web Audio API generates the tones (oscillator + gain envelope, no files). Default **off** (to respect people practising on public transport). The first-session results screen offers it once: "Turn on sounds?".
- **Reduced motion:** under `@media (prefers-reduced-motion: reduce)` (or the in-app "Reduce motion" setting) replace pop/nudge/slide with 120ms opacity crossfades, drop confetti (show a static 🎉 badge), and keep the ring filled without animation.
- **Skeletons:** for any async load (LLM grading, audio warm-up, first load), show `--surface-2` blocks with a 1.2s shimmer gradient. LLM grading shows a "Checking with your tutor…" sheet with three pulsing dots. After 6s it falls back to the local checker and shows the result labelled "(offline check)".
- **Page transitions:** Use the View Transitions API (`document.startViewTransition`) where supported for tab switches (crossfade) and Path node → Lesson (the node circle morphs into the progress bar via `view-transition-name`). No-op elsewhere.

### 5.3 Lesson player (shared shell)

```
┌────────────────────────────────────┐
│ ✕  ▓▓▓▓▓▓▓▓░░░░░░░░░    🔥3        │  ← close (confirm sheet), segmented-feel
│                                    │    progress bar 12px tall, combo counter
│ New word · guess first             │  ← caption, sentence case, accent color
│ <prompt area: flexible>            │
│                                    │
│ <answer area: bottom-anchored>     │  ← answers live in bottom 55%
│ [■ Check ]  (disabled until input) │
└────────────────────────────────────┘
Feedback sheet (slides over the answer area, never pushes layout):
┌────────────────────────────────────┐
│ ✓ Nice!            🔊   ⚑          │  ← ⚑ = "My answer was right" (big target)
│ burro = manteca                    │
│ Tip: -ción → -zione  ⓘ             │  ← one line max; ⓘ expands
│ [■ Continue ]  (green/amber/accent)│
└────────────────────────────────────┘
```
The confidence rating (v1's Sure / Think so / Guessing) stays, but as **three small chips above Check** ("How sure?"). It's optional and remembers the last pick. The fluency-illusion insight moves to the results screen.

**Exercise types:**
- **Multiple choice:** prompt (word or audio) at the top. 2×2 grid of 64px-tall tiles for short answers, or a vertical stack for long ones. Tapping selects (accent border + press). Check confirms. In guess-first mode, the user's pick is outlined and the correct answer turns green; the teaching card **replaces** the options area so nothing scrolls.
- **Type answer:** prompt big. Input is 56px, `autocapitalize="off" autocorrect="off" spellcheck="false" lang="it|de"`. An accent-char bar sits above the keyboard (à è é ì ò ù / ä ö ü ß), 44px keys. Enter = Check. Use `visualViewport` so the Check button rides on top of the keyboard.
- **Word tiles (build sentence):** an answer line (dashed underline, 2 rows high), with a word bank below. Tiles are 48px tall pills. Tapping moves a tile with a 180ms FLIP translate between bank and line; tapping a placed tile returns it. The bank keeps ghost slots so the layout doesn't jump.
- **Listen:** a big 96px play button (accent) plus a 56px "slow" turtle button. A waveform of 5 bars animates while playing. Then choose or type what you heard. If there's no voice available for the language (`speechSynthesis.getVoices()` empty), skip the item silently.
- **Speak:** shows the sentence, with a 🔊 model. A big mic button (96px) pulses with a ring while recording. The transcript appears word by word with matched words in green and missed words underlined amber. "Can't speak now" (text-2 link, 44px) disables speak items for 1 hour. Hide the item when the Web Speech recognition API is unavailable.
- **Match pairs:** two columns of 5 tiles. Tap left then right. A match makes both tiles pop, fade to `--ok-soft`, and lock. A wrong pair does a nudge on both, then deselects. A timer is shown only in speed mode.
- **Flashcard (review / "add from class" cards):** a card with a 3D flip (`rotateY`, `backface-visibility`). Tap to flip. Then 2 big buttons, "Again" / "Got it", with swipe left/right as an accelerator (a threshold of 30% width; the card tilts ±8° while dragging).
- **Speed round:** a mode, not a type. The background shifts to `--accent-soft`, and a 60s **ring timer** wraps the combo counter in the header. Options are big in the bottom half. Correct answers make `+1` float up.

### 5.5 Path (course map)

A vertical, scrollable path of nodes, grouped into **unit banners** (sticky header shows the unit title + postcard illustration, coloured accent). The nodes are 72px circles in a gentle sine-wave layout (x offset = `sin(i*0.9)*60px`).
States: **done** (accent fill, white ✓), **current** (accent ring + pulsing halo + a "Start" bubble above it), **locked** (surface-2, lock icon). There's a **review node** (↻) every 3 lessons and a **checkpoint** (star) at the end of each unit (a test-out is allowed, so placement can jump ahead). Tapping a node opens a bottom sheet: title, 3 example words with audio, "Start · 5 min". Opening the Path auto-scrolls to the current node.

### 5.6 Profile / progress ("Me")

- The header has the user's initial avatar, the language seal switcher, and "Learning since Oct 2026".
- **Goal card:** "A2 by May 2027 · on track ✓" with a horizontal bar (expected vs actual position) and an `Edit goal` link that reopens the goal step.
- **Week strip:** 7 day-rings (Apple Fitness style). Rest days show a small moon, not an empty ring.
- **Words:** one stacked bar, *New · Learning · Strong · Mastered*, with counts. Tapping opens a searchable word list with audio.
- **Skills radar** is overkill; instead show 4 small meters: Listening · Speaking · Reading · Writing (this maps to Nation's strands without the jargon).
- **Insight:** the confidence calibration, as a single card with a 3-row mini chart and a one-sentence takeaway.

### 5.8 Empty, offline, and error states

- **Nothing due + goal done:** Home ring is full: "All caught up. See you tomorrow ☀️" with a secondary "Practise more".
- **Offline:** a slim `wifi-off` pill under the header saying "Offline — practice still works". The AI tutor falls back automatically. Audio uses on-device voices; if none, listen/speak items are skipped.
- **No AI key + free answer:** use the local checker silently. Never show an upsell mid-lesson. One soft mention on results after a free-text miss: "Want explanations? Connect an AI tutor".
- **Empty word list / class cards:** a simple illustration plus one sentence and one button ("Add your first word").
- **Mic denied:** an inline card: "Microphone is off. Speaking exercises are paused." with a link to "How to enable" and a "Keep them off" option.

## 6. Navigation, accessibility, responsiveness

**Navigation: 3 tabs**, Today · Path · Me (bottom tab bar, 64px + safe-area, icon + label, active = accent pill behind the icon). Lessons, onboarding and results are **full-screen modal flows without the tab bar**. Settings is pushed from Me. The language switcher is global, through the seal in the Home/Path header (bottom sheet listing courses + "Add a language"). Why only 3: v1's 4 tabs included 2 that the owner disliked. Fewer choices means the "one next action" principle holds. Routes: `/` (Today), `/path`, `/me`, `/me/settings`, `/me/settings/tutor`, `/lesson`, `/onboarding`.

**Accessibility**
- Contrast: body text ≥ 4.5:1, large text/icons ≥ 3:1 in both themes. Correctness is never conveyed by colour alone (always ✓/✕ icon + word "Correct"/"Not quite").
- Tap targets ≥ 44×44 CSS px (Apple HIG 44pt; Material recommends 48dp, so use 48 for answer tiles and tab items). There's ≥ 8px between adjacent targets.
- Screen readers: the feedback sheet is a `role="status"` live region ("Correct. burro means manteca."). The progress bar is `role="progressbar"` with `aria-valuenow`. Tiles are `<button>`s with `aria-pressed`. Path nodes say "Lesson 3, At the café, current". Words in the target language carry `lang="it"`/`lang="de"` so VoiceOver pronounces them correctly.
- Focus: a visible 2px `--focus` ring on `:focus-visible`, a logical order, and the feedback sheet moves focus to Continue.
- Motion: honor `prefers-reduced-motion` and the in-app toggle. Nothing flashes more than 3 times per second.
- Timers: speed round is opt-in and can be disabled ("No timers" setting, WCAG 2.2.1).
- Text scales with system font size. Layouts use `min-height`, never fixed heights on text containers.

**Responsiveness**
- Phone first: content column `max-width: 480px; margin-inline: auto`. Use `100dvh` and `env(safe-area-inset-*)`.
- At ≥ 768px: the tab bar becomes a left rail (72px, icons + labels), the lesson player stays a centered 520px column with options in a 2-column grid, and the Path shows the unit list at the left with the map at the right. Keyboard shortcuts in lessons: `1–4` choose, `Enter` check/continue, `Space` replay audio, `Esc` close.
- Installed PWA: `display: standalone`, theme-color follows accent + mode.

## 7. Signature moments

1. **The accent swap:** picking Italian or German repaints the whole app (terracotta ↔ Rhine blue) with a 300ms transition. Each course feels like its own world.
2. **Tactile 3D buttons + springy correct "pop"** with haptic tick: every tap feels physical.
3. **The daily ring** closing on results, with a confetti burst from the button and the streak number rolling up (with "rest days" built in, so a streak is never shame).
4. **Goal commitment card** that recalculates live ("12 min/day → A2 by May"): the owner's goal-to-practice ask made tangible.
5. **Placement level meter** sliding A0→B1 as you answer, then the Path auto-scrolls and "unlocks" units you tested out of.
6. **Node morph:** the tapped Path node expands into the lesson progress bar (View Transitions).
7. **Swipeable flashcards** for review: an Instagram-story-like cadence for quick reviews (tap/swipe, one card per screen, a segmented top bar like stories).

_Research notes: Duolingo's 2022 path redesign replaced the skill tree with a single linear path and leaned on animation rather than onboarding pop-ups to teach the UI (Duolingo blog; Mind the Product); Apple HIG 44pt / Material 48dp tap targets; the W3C Vibration API isn't implemented in iOS WebKit, so haptics must be progressive enhancement._
